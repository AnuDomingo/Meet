⚡ Live sync

Connect a free Firebase Realtime Database and everyone who opens a poll link shares the same live data — availability appears the moment someone paints it. No reply codes, no merging, no emails back and forth.

▸ How do I get this URL? (about 2 minutes, free)
  1. Open console.firebase.google.com and create a project (you can skip Google Analytics).
  2. In the left menu pick Build → Realtime Database → Create Database, choose a location, and start in test mode.
  3. At the top of the Data tab you'll see the URL — something like https://my-project-default-rtdb.firebaseio.com. Paste it in the box above.
  4. Open the Rules tab, replace everything with the rules below, and hit Publish.
  5. Hit Save & connect here. Then publish this index.html somewhere both of you can open it (GitHub Pages, Netlify Drop, any web host) and share the poll link.

Anyone holding a poll's random link can read it and add their own availability — the same trust model as an “anyone with the link” doc. Confirming the final time is locked to the organizer: the creator claims a secret key that the database stores write-once and never hands back, so nobody else's attempt to confirm or reopen the meeting is accepted.
